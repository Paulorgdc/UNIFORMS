## 📌 Project Overview

UNIFORMS was developed as an academic project during the *Projeto Integrador Extensionista* for the Bachelor's degree in Software Engineering at UNIVAG.

The platform provides an integrated solution for managing uniform stocks, student requests, and distribution logs. By digitizing inventory control, the system minimizes manual errors, ensures transparency, and accelerates fulfillment workflows for institutional staff.

---

## ⚡ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Architecture:** RESTful API / Relational Data Modeling

---

## 🚀 Key Features

- **Inventory Tracking:** Real-time monitoring of uniform stocks categorized by size, type, and availability.
- **Request Management:** Streamlined workflow for logging, approving, and fulfilling uniform orders.
- **Role-Based Access Control:** Secure authentication with administrative and operational permission levels.
- **Audit & History:** Comprehensive logs tracking stock adjustments, distribution history, and issuance dates.
